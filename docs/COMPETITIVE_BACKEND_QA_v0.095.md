## Authoritative replay behaviour
For every public score submission the server:
1. validates protocol, season, ruleset, build and seed;
2. validates ordered action-log shape and allowed action types;
3. validates the client signature structurally;
4. creates a fresh isolated game VM;
5. starts the exact Seeded Challenge;
6. replays every logged player action against the exact v0.095 game scripts;
7. requires the regenerated action log to match exactly;
8. independently regenerates the final run record;
9. compares victory, score, grade, turn, completion, dependency, reliability, capital, debt, failures, slips, population, architecture, strategy fingerprint, rival readiness and signature;
10. stores the result only after all comparisons pass.

The browser therefore cannot obtain a leaderboard score merely by editing JavaScript variables or inventing a final score.

## Current public-beta limitations
These are not blockers for a small controlled beta, but should be addressed before significant traffic:
- anonymous identity is device/browser-local; there is no account recovery or cross-device sync yet;
- there is no profanity/moderation system for callsigns yet;
- season rotation is environment-configured rather than controlled through an admin dashboard;
- no scheduled database backup job is bundled yet;
- replay currently runs synchronously and takes roughly half a second for a 56-action run in this environment, so a high-volume public launch should move verification to worker threads/queue workers;
- no administrator ban/delete/audit tooling yet;
- no privacy/terms/competition-rules pages yet.

## Launch assessment
The competitive architecture is no longer a fake/local leaderboard. A small public beta can now be deployed with verified server-side replay if persistent server storage is provided.

Before broad promotion, recommended remaining work:
1. worker/queue replay isolation for submission bursts;
2. season lifecycle + countdown/rotation;
3. callsign moderation;
4. DB backups/admin tooling;
5. deploy to the production domain over HTTPS;
6. human beta with several real players submitting concurrent runs.
